## The build (scope is closed — nothing beyond this list)
1. **XR rig + fallback.** XROrigin3D/XRCamera3D/XRController3D with simple visible hand/controller proxies. If OpenXR is not live, a desktop fallback camera + keyboard/mouse driving must work (needed for Hal-side rendered proof; label it as fallback in the panel).
2. **Track.** One ribbon, ~60 s lap at moderate pace: start straight → steep climb → banked corner → GAP (missing section, jumpable at speed with boost, fallable without) → descent → finish straight; then race resets via panel button. Built from segments along a defined path (sampled points, width, per-point height/banking). Stilts down to a distant ground plane; empty sky. The height must READ when looking down.
3. **Car + cockpit.** Primitive-built Odd Rod silhouette (long nose/engine block in view, blower). Cockpit: grab wheel (characterful shape — e.g., wood-rimmed three-spoke; one car only), dash with 3 prep switches, a panel that lists **EVERY command the game accepts** (standing rule: the in-game controls list is complete, updated in the same commit as any added command) plus speed, boost meter, state messages (DROP START / PRESS RELEASE / prep prompt / landing quality / dent state).
4. **Driving model (custom kinematic, Crammond-flavoured arcade-sim).** Car follows the ribbon (path distance + lateral offset); gravity/airborne state over the gap and crests; suspension bounce + landing quality from touchdown pitch/roll/vertical speed (FLAT / OK / ROUGH / HARD); hard landing → dent level +1 and smoke toggle (placeholder visual carnage, deliberately basic). Rationed boost meter, refills only per rules below. Falling off the ribbon (side or gap undershoot) → drone recovery sequence.
5. **Grab wheel steering.** Grip (squeeze) within reach of the wheel grabs it; wheel angle from the grabbing hand's rotation about the wheel axis; steering follows wheel angle (clamp ±180°); release → wheel eases back to centre. Two-hand grab allowed, last-moved hand wins or average — pick one, document it. Throttle: right trigger. Brake/reverse: left trigger. Boost: right controller primary button (A) while driving. Desktop fallback equivalents for all, listed on the panel.
6. **Drop Start.** Race begins suspended under the drone beside/above the start: pendulum sway (spring simulation — the sway must move the car AND the view), your prep switches available, prompt to press-and-hold nothing — a single release press (right trigger) drops you when YOU choose. Score the touchdown (flat four-wheel = FLAT). Drone visibly quadcopter-from-primitives, 4 lift lines to the car corners, tilts as it moves.
7. **Drone recovery (the centrepiece).** Triggered by falling, AND on demand by a panel-listed command (practice key/button — Chris must be able to judge the lift without waiting for a fall). Sequence: drone arrives → lines attach → car lifts off the ground/void, swings as a pendulum load while the drone carries it to the nearest suitable straight section → while dangling, the **prep mini-sequence**: panel shows a random order of the 3 dash switches; player reaches (hand near switch + grip/trigger) and flips them in order, while swaying; completing the sequence grants **a little boost credit** (spec item 5, decided) shown on the meter; wrong switch resets the sequence. Player presses release (right trigger) when over the track → drop, touchdown scored; releasing while NOT over the track → you fall and the drone catches you again (original's rule). Time in lift is unhurried — it takes a while, by design.
8. **Lean-for-traction EXPERIMENT (spec item 15).** Toggle on the panel (and desktop key). When ON: HMD lateral offset from a neutral captured at Drop Start gives a grip multiplier (lean into turn = more grip on the bank; wrong way = less), shown on a dash indicator. Desktop fallback: two keys simulate lean L/R. The banked corner must be makeable with lean OFF (bonus, never required).
9. **Reset/view commands.** Recenter view command; restart-race command; quit-to-start command. All on the panel list.
